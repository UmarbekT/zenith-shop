# Zenith mini shop

HTML, CSS va JavaScript yordamida tayyorlangan maktab loyihasi.

## Ishga tushirish

`index.html` faylini brauzerda oching. Internetdagi rasmlar ko'rinishi uchun internet ulanishi kerak.

## Funksiyalar

- Soatlar katalogi va qidiruv
- Mahsulot nomi, narxi, rasmi va tavsifini `js/data.js` ichida o'zgartirish
- Yangi mahsulot qo'shish uchun `PRODUCTS` massiviga yangi obyekt qo'shish
- Savatga qo'shish, miqdorni oshirish/kamaytirish
- Ro'yxatdan o'tish va login uchun localStorage xotirasi
- Savat va buyurtmalarni localStorage xotirasida saqlash
- Logo uchun `.logo-placeholder` joyi

## Mahsulot qo'shish namunasi

```js
{id:7,name:'Yangi Zenith',category:'Classic',price:1000000,image:'rasm-url',description:'Yordamchi tavsif'}
```

Bu serverli haqiqiy auth emas, maktab loyihasi uchun brauzer xotirasidagi demo auth hisoblanadi.
